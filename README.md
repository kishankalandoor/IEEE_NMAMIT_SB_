# IEEE NMAMIT Student Branch

Welcome to the official website of IEEE NMAMIT Student Branch at NMAM Institute of Technology, Karkala.

## About

IEEE NMAMIT Student Branch is the local chapter of the Institute of Electrical and Electronics Engineers (IEEE) at NMAM Institute of Technology. We are dedicated to advancing technology for humanity and providing students with opportunities for technical and professional development.

## Website

- **Live Site**: [ieeenmamit.js.org](https://ieeenmamit.js.org)
- **GitHub Pages**: [kishankalandoor.github.io/IEEE_NMAMIT_SB_](https://kishankalandoor.github.io/IEEE_NMAMIT_SB_/)

## Features

- Information about IEEE NMAMIT Student Branch
- Upcoming events and workshops
- Membership details
- Contact information
- Gallery of past events

## Development

This website is built using HTML, CSS, and JavaScript, and is deployed using GitHub Pages.

### Local Development

1. Clone the repository
2. Open `index.html` in a web browser
3. Make your changes and test locally

### Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the `main` branch.
